### Selected work

**[VisionGuard](https://github.com/yahyabenturkia/visionguard)** — automated inspection machine for aerospace ceramic cores
Designed and built end to end: SolidWorks rig, STM32 motion control, Raspberry Pi 5
acquisition, ResNet18 classifier. **94.2 % accuracy, ROC-AUC 0.996, 1 min per part
against a 3 min target.**

**[Person-Following Robot](https://github.com/yahyabenturkia/Autonomous-vision-based-person-following-robot-using-YOLO-and-Realsense)** — real-time visual tracking with depth-based control
YOLO detection, MediaPipe keypoints, RealSense depth, proportional velocity control
over Modbus TCP. **30 FPS, ±0.10 m distance holding.**

**[3D Gait Analysis](https://github.com/yahyabenturkia/Gait-Analysis-3D)** — markerless clinical gait metrics from one camera
YOLOv8 + MMPose, 3D reconstruction, sagittal joint kinematics, Kalman/RTS smoothing,
automated PDF reporting.
